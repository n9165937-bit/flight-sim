# Skyward — Flight Simulator

A browser flight sim with 8 aircraft (Skylark trainer, Vortex aerobatic, Kestrel twin, Meridian jet, PC-12, F-16, F/A-18, F-22), two maps (Green Valley and Red Rock Canyon), landing practice with scoring, ring courses, wind, and live multiplayer.

**Play:** https://n9165937-bit.github.io/flight-sim/

## Multiplayer
Open the game, type a pilot name in the menu, and fly. Everyone on the same map sees each other's planes with name tags. Positions are shared through a free public relay (HiveMQ), so there's nothing to set up — just send friends the link.

## Controls
W/S pitch · A/D roll · Q/E rudder · Shift/Z throttle · F/V flaps · G gear · B brakes · K Cobra (fighters) · C camera · R reset · Esc menu
